# Homelab Project
This repo is intended to track my progress in building my homelab and to hold all documentation, scripts, and other files and information related to it.

## Goal: Build a private server running off my home network to:
* **Learn networking and cybersecurity concepts and go beyond theory to implement them in real time**
* Construct a Proxmox hypervisor with multiple VMs to server as a sandbox environment
* Apply effective system and network administration by architecting and managing interactions between VMs on a shared network
* Iteratively architect and enact system and network security infrastructure as it is learned
* Write meaningful scripts to automate and assist in maintaining and improving system security
